# QR Attendance Management System

A mobile application developed as part of a university
project to manage student attendance using QR codes.

## Project Documentation

The `docs/` directory contains the project documentation:

- General Introduction and Feasibility Study
- Stakeholders, Actors and Permissions
- Software Requirements Specification
- Use Cases and Acceptance Tests

## Diagrams

The `docs-diagrams/` directory contains system diagrams.

## Application

The Flutter application will be developed inside
the `app/` directory.
